# Rubic Cube - Resend Inspired

A light-theme, metallic Rubik's Cube-inspired WebGL prototype with animated mechanical slices and selectable metal finishes.

## Preview

[Open the live Vercel preview](https://rubic-cube-resend-inspired.vercel.app/)

## Run locally

Open [`light_theme_cube_metal.html`](./light_theme_cube_metal.html) in a modern browser, or serve this folder with any static file server:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000/>.

## Notes

- The page uses Three.js from the cdnjs CDN.
- WebGL is required.
- The repository intentionally tracks only the metallic light-theme page and the files needed to document and deploy it.
