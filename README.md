# Rubic Cube - Resend Inspired

A light-theme, metallic Rubik's Cube-inspired WebGL prototype with animated mechanical slices and selectable metal finishes.

## Preview

[Open the live Vercel preview](https://rubic-cube-resend-inspired.vercel.app/)

## What this is

This is an original cube animation prototype created for this repository. It was not copied from the Resend website or another project's source code. The visual direction is inspired by the look and motion of a reference experience, while the implementation, geometry, animation, styling, and controls here were authored for this project.

The page uses [Three.js](https://threejs.org/) from the [cdnjs CDN](https://cdnjs.com/libraries/three.js). Three.js is an independent open-source library and remains subject to its own license; it is not included in this repository.

## Run locally

Open [`light_theme_cube_metal.html`](./light_theme_cube_metal.html) in a modern browser, or serve this folder with any static file server:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000/>.

## Notes

- The page uses Three.js from the cdnjs CDN.
- WebGL is required.
- The repository intentionally tracks only the metallic light-theme page and the files needed to document and deploy it.
